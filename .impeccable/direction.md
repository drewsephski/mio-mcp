# User-approved direction

THESIS: A compact, private notes workspace whose landing page demonstrates capturing a thought and keeping its files beside it.
OWN-WORLD: White and cool off-white surfaces, ink text, clear blue actions, Geist typography, thin neutral dividers, consistent line icons.
STORY: Understand the private note workflow, create an account, write a note, and attach a file.
FIRST VIEWPORT: Left-aligned editorial headline and blue account CTA beside a large, labeled example of the actual three-column workspace. Dashboard uses a narrow navigation rail, searchable note list, and spacious editor.
FORM: User-pinned crisp-white compact interface; seed key user-pinned-blue-code. No visual mockup is required under the user's code-first selection.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

SIGNATURE INTERACTION: The landing-page example lets visitors select three sample notes and see the editor content change without any persistence. The dashboard uses explicit save and quiet status feedback; archive and attachments preserve the same note-and-context model.
MOTION: Brief color transitions on controls; no entrance animation or hidden content. Smooth anchor scrolling respects reduced-motion preference.
QUALITY BAR: Precise alignment, readable note content, compact functional controls, restrained blue, clear privacy and example labeling, responsive access to every workspace action.
